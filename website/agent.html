Policy agent

Ask how policy should adapt when weather, not just emissions, drives air quality. The agent reads only the sourced facts below, then returns three options with evidence, trade-offs and how strong the evidence is.

This page has no server of its own, so your question goes from this browser tab straight to Groq. The key is kept only in this tab and is never saved to GitHub. Use a key you can revoke afterwards.

These are options for officials to weigh, not decisions. Fact ids (F1…) show which source each claim rests on; hover one to read it.
