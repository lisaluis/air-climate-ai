# Website (Task 1)
Open `index.html` in a browser (no build step). `agent.html` needs the Flask app or Colab (see root README).
Files: `data.js` (all numbers + sources), `index.html` (structure), `style.css` (design tokens), `app.js` (rendering), `agent.html` + `agent.js` (agent UI), `SPEC.md`.
Publish: repo Settings > Pages > deploy from `main` / `/website` (the agent page then shows how to run its server).
Before sharing: set `repo` in `data.js` to your GitHub path so the Colab link works, and verify the figures against the Times of India article.
